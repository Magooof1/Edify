## The rule this file exists for

Justin, 2026-10-05: *"Is there a way to organise the data so things aren't getting missed…
If I can't remember to look, we aren't going to get better."*

In one working day the workforce designed a mailer without opening the control that was in
the repo; built a mockup without opening the brand assets supplied three weeks earlier;
inferred the control's fold from its file header instead of measuring its contents; told
Justin nobody had counted the warm list when it was sized in `ROADMAP.md`; said the
Facebook quiz's numbers were unknown when they were in his own ad account; and briefed an
agent to write five class questions without opening the 107 slides — which, when finally
opened, showed one of the questions is not taught.

Every one of those was a thing we already had. The record is organised by **when we learned
it**, so answering "what do we know about X" means reading 4,300 lines of dated entries.
Nobody does that, so everybody re-derives.

**Two mechanical rules, not reminders:**

1. **Every brief names the files the agent must open.** This file is where that list comes
   from. A brief without file names is a brief that will re-derive.
2. **A claim that something is unknown has to cite this file.** "Nobody has counted X" is
   only sayable after checking here.
